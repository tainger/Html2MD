# Html2MD · 网页转 Markdown

<img src="icons/icon128.png" width="96" alt="Html2MD 图标">

一键将当前网页文档转换为 Markdown 的 Chrome 扩展（Manifest V3）。点击插件图标即可预览转换结果，支持复制到剪贴板或下载 `.md` 文件。

- **零依赖**：转换引擎为纯手写 JavaScript，不引入任何第三方库
- **轻权限**：仅申请 `activeTab` + `scripting`，无后台常驻脚本、无网络请求
- **结构保留**：标题、列表、代码块、表格、引用等 Markdown 元素完整输出

## 功能特性

- **四种转换范围**：自动识别 / 智能正文 / 仅选中区域 / 整个网页
- **智能正文抽取**：优先识别 `article`、`main`、`.markdown-body` 等常见容器，自动剔除导航、广告、脚本等噪音节点
- **结果预览**：弹窗内直接展示 Markdown 源码与字符数统计
- **一键复制 / 下载**：复制到剪贴板，或以页面标题命名下载 `.md` 文件
- **相对链接绝对化**：基于当前页面 URL 自动补全相对路径的链接与图片
- **代码语言识别**：自动识别 `language-xxx` 类名并输出带语言标注的围栏代码块
- **行内三反引号自动修复**：部分云文档页面用样式而非 `<code>` 表达行内代码，正文里直接残留成对的 `` ```code``` `` 文本（会打开未闭合围栏、吞掉后文）。转换器以围栏状态机感知代码块边界，仅把围栏外的成对三反引号收缩为单反引号，代码块与日志 dump 中的原文绝不误伤

## 安装方法

本扩展未上架 Chrome 网上应用店，请通过「开发者模式」本地加载：

1. 下载或克隆本仓库到本地
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
3. 打开右上角的 **开发者模式** 开关
4. 点击 **加载已解压的扩展程序**，选择本项目根目录（包含 `manifest.json` 的目录）
5. 工具栏出现 M 形图标即安装成功，建议点击「固定」方便使用

> Edge、Arc 等 Chromium 内核浏览器同样适用，入口分别为 `edge://extensions/` 等对应扩展管理页。

## 使用方法

1. 在任意普通网页（`http://` / `https://`）点击工具栏的 Html2MD 图标
2. 弹窗自动完成转换并展示 Markdown 内容，顶部显示本次使用的范围与字符数
3. 通过弹窗顶部下拉框切换转换范围，切换后自动重新转换
4. 点击 **复制** 将 Markdown 复制到剪贴板，或点击 **下载 .md** 保存文件

**只转换网页中的一部分**：先用鼠标在页面上选中目标内容，再点击图标（「自动」模式会优先使用选中区域）。

## 转换范围

| 选项 | 行为 |
| --- | --- |
| 自动（选中区域 / 正文） | 页面上有文本选中时转换选中区域，否则走智能正文 |
| 智能正文 | 在常见文章容器中选取文字量最多的一个，过滤导航/广告等噪音 |
| 仅选中区域 | 只转换当前鼠标选中的 HTML 片段，不补页面标题 |
| 整个网页 | 转换整个 `<body>`（会额外移除 `nav`、`header`、`footer`、`aside` 等结构性噪音） |

智能正文找不到合适容器时，会自动兜底为整个网页。

## 支持的 Markdown 元素

| HTML | Markdown 输出 |
| --- | --- |
| `h1` ~ `h6` | `#` ~ `######` 标题 |
| `p` | 段落 |
| `strong` / `b` | `**粗体**` |
| `em` / `i` | `*斜体*` |
| `del` / `s` | `~~删除线~~` |
| `a` | `[文本](URL "标题")`，相对路径自动转绝对路径 |
| `img` | `![alt](URL)` |
| `ul` / `ol` | `- ` 无序、`1. ` 有序列表，支持多层嵌套与 `start` 属性 |
| `blockquote` | `> ` 引用块 |
| `pre` / `code` | ```` ``` ```` 围栏代码块 / `` ` `` 行内代码，自动识别语言 |
| `table` | GFM 表格（无表头时自动补空表头，单元格内 `\|` 自动转义） |
| `hr` | `---` |
| `br` | 行尾两空格的硬换行 |

此外还会：转义正文中的 Markdown 特殊字符（反斜杠、反引号、星号、下划线、波浪号、方括号、`#`、`>` 等）；用 `<URL>` 包裹含括号或空格的链接地址；丢弃 `script`、`style`、`iframe`、表单控件及 `[hidden]`、`[aria-hidden]` 节点。

## 项目结构

```
Html2MD/
├── manifest.json   # 扩展配置（Manifest V3、权限、弹窗入口、图标）
├── converter.js    # 零依赖 HTML → Markdown 转换引擎，暴露 window.Html2MD
├── popup.html      # 弹窗页面结构
├── popup.css       # 弹窗样式
├── popup.js        # 页面内容抽取、调用转换、复制/下载交互
└── icons/          # 16/32/48/128 四种尺寸扩展图标
```

## 实现说明

- 点击图标时，`popup.js` 通过 `chrome.scripting.executeScript` 把抽取函数注入当前标签页，在页面上下文中克隆并清洗目标 DOM，再把 HTML 回传到弹窗
- `converter.js` 使用 `DOMParser` 解析 HTML，按「块级递归 + 行内渲染」两遍处理：块级元素（标题、列表、表格、代码块等）逐个生成对应 Markdown 结构，行内元素（链接、图片、强调等）在段落内渲染并做空白折叠与特殊字符转义
- 全程在浏览器本地完成，不发起任何网络请求

## 隐私说明

- 扩展只在用户点击图标时读取当前标签页的页面内容（`activeTab` 机制），不会在后台收集或上传任何数据
- 不申请主机权限（`host_permissions`），不访问 Cookie、浏览历史等无关数据

## 常见问题

**点击图标后提示「当前页面不允许扩展访问」？**
`chrome://`、Chrome 网上应用店、PDF 内置预览等特殊页面禁止任何扩展注入，属于浏览器限制，请在普通网页中使用。

**如何转换本地 HTML 文件（`file://` 页面）？**
在 `chrome://extensions/` 的 Html2MD 详情页中，打开 **允许访问文件网址** 开关后即可使用。

**智能正文抽取不准怎么办？**
可切换为「仅选中区域」手动框选内容，或使用「整个网页」全量转换。

**修改代码后不生效？**
在 `chrome://extensions/` 点击本扩展卡片上的「重新加载」按钮即可；代码全部为本地文件，无需构建步骤。
